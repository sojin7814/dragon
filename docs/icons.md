# 아이콘·앱 이름 교체

현재 아이콘은 사용자가 전달한 용·달력·골프 이미지입니다. 전달받은 PNG 원본을 `assets/icon-original.png`에 바이트 그대로 보관했습니다. 이미지를 다시 그리거나 색상·요소·구도를 변경하지 않았습니다.

1. `assets/icon-original.png`가 현재 생성 원본입니다. 다른 원본으로 교체할 때는 가로·세로 512px 이상인 원본 PNG를 보관하세요. 작은 이미지를 반복 확대하지 마세요.
2. `pnpm icons`를 실행합니다. 다른 파일을 직접 지정하려면 `pnpm icons assets/final-icon.png`를 사용합니다.
3. `pnpm build` 후 `pnpm preview`로 화면·설치 아이콘을 확인합니다.

`public/icons/`에 다음 PNG가 생성됩니다.

| 파일 | 크기 | 처리 |
|---|---|---|
| `icon-512.png` | 512×512 | 원본 전체 축소 |
| `icon-192.png` | 192×192 | 원본 전체 축소 |
| `apple-touch-icon.png` | 180×180 | 원본 전체 축소 |
| `favicon-32.png` | 32×32 | 원본 전체 축소 |
| `maskable-512.png` | 512×512 | 원본 전체를 288×288로 축소하고 사방 112px 여백 추가 |

마스크 대응 파일은 휴대폰이 원형이나 둥근 모양으로 잘라도 원본 그림이 안전 영역 안에 남도록 여백을 둡니다. 원본의 오른쪽 아래 끝 픽셀에서 읽은 짙은 녹색 `#0d2a1e`를 **새로 추가하는 여백에만** 사용합니다. 원본의 색은 변경하지 않습니다. 확대·잘라내기·요소 재배치·생성형 이미지 편집을 사용하지 않습니다. 일반 아이콘 4종에는 별도 여백을 추가하지 않습니다.

생성 명령은 크기·PNG 형식과 원본 불변을 검사하고, `assets/icon-verification.json`에 원본 및 각 결과의 SHA256과 처리 방식을 기록합니다. 같은 원본·잠금 파일·Sharp 버전으로 다시 생성하면 같은 파일을 얻을 수 있습니다. 초기 임시 원본 `assets/icon.svg`는 미사용 참고 파일이며 현재 생성이나 공개 앱에는 포함되지 않습니다.

표시 이름과 기본 색은 `assets/app.json`에서 바꿉니다. 화면과 manifest에서 같은 설정을 사용합니다. 아이콘 교체 때문에 저장 키·앱 설치 ID·공개 URL·서비스워커 범위를 바꾸지 않습니다.

OS가 이전 아이콘을 보관할 수 있으므로 모든 기기의 홈 화면 아이콘이 즉시 바뀌지는 않습니다. 아이콘을 바꾸려고 개인 기록부터 삭제하지 마세요. 재설치를 고려한다면 원래 환경의 기록을 먼저 백업합니다.
