# 앱 주소와 QR 안내

승인된 앱 주소는 **[https://sojin7814.github.io/dragon/](https://sojin7814.github.io/dragon/)**입니다. 이 주소로 PNG·SVG·A4 안내문·카카오톡 이미지를 생성했고 독립 디코더에서 주소 일치를 확인했습니다. **공개 배포와 실제 접속 확인은 아직 남아 있습니다.** QR 이미지가 준비됐어도 링크에서 앱이 열리는지 확인한 뒤 동료에게 배포하세요.

## 같은 주소로 다시 만들기

1. 현재 로컬 `.env`에는 `VITE_PUBLIC_URL=https://sojin7814.github.io/dragon/`가 설정되어 있습니다. 다른 PC라면 `.env.local`에 같은 값을 적습니다. 마지막 `/`까지 동일하게 유지하고 개인 이름·휴무조·메모나 `?` 뒤 추가 정보를 넣지 않습니다.
2. 앱 주소·안내 문구·아이콘 등을 수정했다면 앱을 다시 빌드하고, 아래 명령으로 QR 안내 파일을 만듭니다.
3. 실제 전달 전에는 GitHub Pages에서 앱이 열리는지 확인합니다. 현재는 이 공개 접속 확인이 남아 있습니다.

```powershell
pnpm qr
```

명시적인 승인 주소를 직접 줄 수도 있습니다.

```powershell
pnpm qr --url https://sojin7814.github.io/dragon/
```

위 명령은 승인된 실제 배포 대상 주소를 사용합니다. 자동 검사로 모든 임시 주소나 개인정보를 판별할 수 있는 것은 아니므로 주소를 바꿀 때는 새 대상이 확정되었는지 확인해야 합니다. 외부 QR 생성 서비스나 단축 주소는 사용하지 않습니다.

현재 `generated/qr/`에 다음 파일을 생성했습니다. 명령을 다시 실행하면 갱신합니다.

| 파일 | 용도 |
|---|---|
| `dragon-calendar-qr.png` | 이미지 저장·전달 |
| `dragon-calendar-qr.svg` | 크게 인쇄해도 선명한 원본 |
| `a4-install-guide.html` | 브라우저에서 열어 A4 인쇄 |
| `kakao-share.png` | 카카오톡에 첨부할 안내 이미지 |
| `kakao-message.txt` | 실제 링크가 들어 있는 함께 보낼 문구 |
| `verification.json` | 디코딩 주소 일치 결과와 실기기 미검증 표시 |

PNG, SVG를 PNG로 변환한 결과, 카카오톡 완성 이미지의 QR을 생성 라이브러리와 다른 **jsQR**로 읽어 주소가 정확히 같은지 확인합니다. 현재 세 결과 모두 승인 주소와 일치했습니다. 하나라도 실패하면 생성 작업이 오류로 끝납니다. 개인 기록에는 접근하지 않습니다. 이 검사는 인터넷에서 앱이 공개되어 있는지 확인하는 검사가 아닙니다.

`pnpm qr --self-test`는 예약된 테스트 도메인으로 메모리 안에서만 QR·디코더를 시험합니다. 파일이나 운영 QR을 내보내지 않습니다.

## 인쇄와 카카오톡 전달

- A4 안내문을 브라우저에서 열고 인쇄 버튼을 누르세요. A4 용지·배율 100%로 미리보기를 확인하고 QR 주변의 흰 여백을 자르지 마세요.
- 카카오톡에는 이미지와 `kakao-message.txt`의 링크 문구를 함께 전달하세요. 같은 휴대폰에서는 링크를 누르고, 종이·다른 PC에 보이는 QR은 카메라로 찍습니다.
- QR이 앱 주소를 열어주더라도 설치는 기기 안내에 따라 직접 진행합니다. 개인 기록을 옮기려면 QR이 아니라 백업·복원을 사용합니다.
- 주소가 바뀌면 이미 인쇄한 QR은 새 주소로 자동 변경되지 않습니다. 고정 주소를 먼저 확정하세요.

## 아직 해야 하는 실제 확인

종이에 인쇄한 QR과 PC 화면의 QR을 아이폰·갤럭시 카메라로 읽어 **같은 최종 주소**가 열리는지 확인하세요. 자동 디코딩은 이 실제 촬영 시험을 대신하지 않습니다. 확인 전에는 ‘실기기 미검증’으로 표시합니다.

이 폴더의 [A4 구성 템플릿](a4-template.html), [카카오톡 이미지 구성 템플릿](kakao-template.svg), [카카오톡 문구 초안](kakao-message-template.txt)은 편집 참고용입니다. 템플릿의 QR 자리는 빈 칸이며, 실제 QR이 포함된 완성 파일은 `generated/qr/`에서 확인하세요. 공개 접속과 휴대폰 촬영 확인이 끝난 뒤 완성 파일을 배포합니다.
