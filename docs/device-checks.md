# 실제 기기 확인표

2026-09-20. 외부 기본 캘린더 연동은 제거했습니다. 아래 설치·실행 항목은 PC 자동 검증과 구분하며 실제 기기에서 확인하기 전에는 **미검증**입니다.

| 환경 | 확인할 항목 | 실기기 상태 |
|---|---|---|
| Android Chrome | 앱 버튼 → 실제 설치창 → 설치 → 홈 화면 아이콘 | 미검증 |
| Samsung Internet | 준비된 설치 버튼 → 실제 설치 확인창 | 미검증 |
| Android 홈 화면 앱 | standalone 실행, 설치 안내 숨김, 기존 기록 유지 | 미검증 |
| 카카오톡 내부 브라우저 | 짧은 안내·주소 복사 후 외부 브라우저에서 설치 | 미검증 |
| iPhone/iPad Safari | 공유 → 홈 화면에 추가 → 추가, 아이콘 실행 | 미검증 |
| PC Chrome/Edge | 지원 시 실제 설치 버튼·앱 실행 | 미검증 |

## 기기에서 확인하는 순서

1. 공개 앱 https://sojin7814.github.io/dragon/ 을 Android Chrome에서 엽니다. 검증용 기록은 실제 사용자 기록과 구분합니다.
2. 7가지 근무 유형과 내부 월간 달력이 표시되고 외부 캘린더 관련 버튼·도움말이 없는지 확인합니다.
3. 근무 유형·양도·교환·메모·휴무 계획·테마·변경 이력을 기록하고 백업합니다.
4. 준비된 ‘홈 화면에 설치’를 누릅니다. 실제 브라우저 설치 확인창이 나타나는지 확인합니다. 취소 시 앱을 계속 사용할 수 있어야 합니다.
5. 다시 설치 이벤트가 준비되면 설치합니다. 홈 화면 아이콘으로 열어 주소창 없는 standalone 화면인지, 설치 버튼이 사라졌는지, 3번의 기록이 모두 남아 있는지 확인합니다.
6. 카드 닫기 후 같은 날 다시 열어 카드가 반복되지 않는지 확인합니다. 준비된 설치 버튼은 설정에서 사용할 수 있습니다.
7. 오프라인 준비 후 인터넷을 끊고 재실행해 달력·메모가 유지되는지 확인합니다.
8. Samsung Internet에서도 1~7을 별도로 확인합니다. 다른 브라우저의 저장소는 다르므로 기록 이전에는 백업·복원을 사용합니다.
9. 카카오톡에서 링크를 열면 설치 버튼을 억지로 띄우지 않고 안내와 주소 복사를 제공하는지 확인합니다.
10. 종이·PC 화면 QR을 실제 카메라로 읽고 같은 공개 주소와 설치 흐름이 열리는지 확인합니다.

## 업데이트

- 새 버전 배포 후 재설치 없이 적용되고 기록·테마가 유지되어야 합니다.
- 미저장 입력·백업 복원·설치 확인창이 열려 있을 때는 업데이트가 기다려야 합니다.
- 탭 2개 중 하나가 작성 중이면 입력을 보호하고, 저장 또는 닫기 후 안전하게 적용해야 합니다.
- 다운로드 실패·오프라인에서는 이전 정상 버전을 사용할 수 있어야 합니다.
- 쿠키·사이트 데이터 삭제나 앱 재설치를 업데이트 절차로 요구하지 않습니다.
